# パステル上海 ～癒しの麻雀パズル～

スマートフォンの縦画面を中心に制作した、日本語の上海（麻雀ソリティア）です。HTML / CSS / JavaScript、オリジナルSVG牌、Web Audioによるオルゴールを使用しています。外部フォント・CDN・通信API・追加パッケージは不要です。

## 起動

Node.js 20以降を用意し、このプロジェクトのフォルダーで実行します。

```sh
node scripts/serve.mjs
```

ブラウザで http://localhost:4173 を開いてください。停止はターミナルの Ctrl+C です。HTMLの直接ダブルクリックでは、ES Modules / PWAが動作しないため、必ずHTTPサーバーを利用します。npmを使える環境では `npm start` も同じ動作です。

## 遊び方

- 上に牌がなく、左右どちらかが空いた「自由牌」を2枚選びます。同じ絵柄なら消えます。暗く表示される牌は選べません。
- 花牌（梅・蘭・菊・竹）は花牌どうし、季節牌（春・夏・秋・冬）は季節牌どうしでマッチします。字牌・数牌は同じ絵柄のみです。
- すべて消すとクリア。消せるペアがない場合には手詰まりを知らせます。
- ステージは全100面。20面ずつ5章に分かれ、クリアすると次の面が解放されます。フリーモードは初級・中級・上級をいつでも選択でき、毎回ランダムな配置です。
- ヒントは現在選べるペアを光らせます。「1手戻す」は除去とシャッフルの直前の盤面を復元します。時間やサポート使用回数は戻りません。
- 1ゲームにつき **ヒント3回・シャッフル2回・1手戻す3回** まで使用できます。ボタンに残り回数を表示し、0回になると無効になります。使用回数は既存の自動保存データに含まれ、再読み込み・一時停止・アプリ再起動では復活しません。新しいゲームと「やり直し」でリセットします。失敗した操作には回数を消費しません。
- シャッフルは残り牌の絵柄・枚数を保ち、解答手順を作って再配牌します。形状自体が解けなくなっていた場合は残り牌を平面へ並べ直します。実行前に画面でも案内します。
- シャッフル確定後は約1.5秒、牌が浮いて左右に混ざる演出と12個のきらめきを表示します。開始・混合・完了の効果音は設定の「効果音」に従います。OSやブラウザの「視差効果を減らす／動きを減らす」設定では、約0.22秒のフェードだけに切り替えます。
- 演出中はすべての操作をロックします。盤面データは演出終了後にまとめて更新し、中断・再読み込みでは演出前の有効な状態から再開できます。途中で別タブへ移動した場合には一時停止を維持します。
- 「やり直し」は最初の配牌、時間、使用回数へ戻します。
- 「拡大」で盤面を拡大し、盤面内をスワイプ／スクロールできます。通常のゲーム画面全体はスクロール不要です。
- 一時停止や別タブへの移動では時計と音楽が止まります。再開操作で復帰します。
- 「リタイア」は確認後、進行中のゲームを終了してステージ選択へ戻ります。フリーモードからも同じ画面へ戻ります。過去の星・解放状況・ベストタイムは残り、リタイアしたゲームはクリア扱いにしません。
- 手詰まりは現在の自由牌判定に基づいて自動検出します。シャッフルが残っていれば続行を案内し、残り0回なら「やり直す」「リタイア」を案内します。戻す回数と履歴があれば「1手戻す」も利用できます。シャッフル後・戻す後・保存からの再開時にも再判定します。シャッフル失敗時は元の盤面と残り回数を保持して案内します。
- 設定からBGM・効果音をそれぞれ切り替えられます。ユーザー操作後に音声を有効化します。BGMは独自の32音フレーズをサイン波で合成したオルゴール風の楽曲です。

### 成績

| 星 | 条件 |
| --- | --- |
| 3 | ヒント・戻す・シャッフルなし、初期牌数×12秒以内でクリア |
| 2 | シャッフル1回以下、ヒント3回以下でクリア（星3条件を満たさない場合） |
| 1 | それ以外のクリア |

星は各ステージの最高成績を保持します。フリーのベストタイムは難易度ごとに記録します。サポート使用時もタイム記録の対象です。

## 解ける配置の保証

`src/engine.js` が100個の異なる座標構成を決定的に生成します。序盤は少数の平面配置、後半は最大3層へ複雑化します。章ごとの平均牌数は16 / 30.8 / 43.2 / 77.1 / 89.6枚です。全ステージの配置に重複がないことをテストします。

配牌は、絵柄がない盤面から自由牌を2枚ずつ仮除去し、その全除去順序のペアにマッチする絵柄を割り当てます。ランダムな仮除去で完了できなければ、左右対称な各行の外側から取り除く保証手順へフォールバックします。結果として必ず少なくとも1つの解答手順が存在します。プレイヤーが別のペアを取ると手詰まりになることはあります。

自由判定は座標の矩形交差を利用し、部分的な上面の重なり・左右で縦位置が部分的に重なる場合も判定します。単純な配列の隣接判定ではありません。

## 自動保存

同一ブラウザ・同一URLの `localStorage` に、盤面、直近200手までの戻す履歴、経過時間、解放状況、最高成績、設定を保存します。除去・サポート操作・画面離脱時およびプレイ中4秒間隔で保存します。最後の4秒以内の経過時間は突然のプロセス終了で戻る場合があります。

スキーマ検証と前回の有効データのバックアップを実装しています。破損時はバックアップを利用し、両方が利用できなければ初期状態へ復帰して通知します。保存容量不足などは画面通知します。ブラウザのサイトデータを削除すると記録も削除されます。進行中ゲームは1件です。別のゲームを開始すると進行中データを置き換えます。

今回の回数制限追加では、保存キー `pastel-shanghai-v1` と保存形式・保存方式を変更していません。以前のクリア成績・星・ベストタイムをそのまま使用します。旧バージョンでお助け機能を上限より多く使った途中データも読み込め、その機能の残り回数は0になります。Safariとホーム画面アプリで別の保存領域が使われる環境では、それぞれの記録を保持します。データ移行や初期化処理は追加していません。

## PWA・オフライン

初回にオンラインで一度読み込むと、Service Workerがゲーム本体とアイコンをキャッシュし、その後はオフラインでも起動できます。サーバーからの追加取得は不要です。ブラウザの「アプリをインストール」またはSafariの「共有 → ホーム画面に追加」を使用できます。

PWAにはHTTPSまたはlocalhostが必要です。スマートフォンからLAN内のPCのHTTPアドレスを開く場合は通常プレイはできますが、PWA・オフライン機能にはHTTPS配信を利用してください。インストールの表示方法は端末・ブラウザにより異なります。

## テスト・ビルド

```sh
node --test
node scripts/build.mjs
node scripts/serve.mjs --dist
```

テストはNode.js標準のテストランナーを使用します。ルール、特殊牌、全100面×4配牌の全手順、フリー3難易度×25配牌、手詰まり、ランダム操作後のシャッフル、牌の種類と枚数の保持、戻す、星、解放、保存復旧、PWAキャッシュとアイコンを検証します。

`dist/` が公開用成果物です。`npm test` / `npm run build` / `npm run dev` も利用できます。アイコン再生成は `node scripts/icons.mjs` です。

### 手動確認

1. 開発者ツールで390×844、360×640、320×568を選び、盤面と操作ボタンの表示、タップ、拡大・盤面移動を確認します。
2. 自由牌を消し、戻すで復元。ヒント・シャッフル・やり直しを確認します。
3. 一時停止／別タブ移動で時計が止まること、再読み込み後「つづきから」で復元することを確認します。
4. クリアして星が付くこと、次のステージを遊べることを確認します。
5. 初回読み込み完了後、開発者ツールをOfflineにして再読み込みし、ホーム画面からゲームを開始できることを確認します。
6. 実機でホーム画面への追加、音声ON/OFF、オフライン再起動を確認します。

## 構成

- `src/engine.js`: 配置生成、上海ルール、解答保証、成績
- `src/storage.js`: バージョン付き保存・検証・復旧
- `src/tiles.js`: 数牌・字牌・花牌・季節牌のSVG描画
- `src/audio.js`: オリジナルBGM・効果音の合成
- `src/app.js` / `src/style.css`: 画面・操作・レスポンシブ表示
- `src/readability.css`: 14px以上を基本にした文字・コントラスト・省スペース配置
- `src/shuffle-animation.js`: 座標判定に影響しないシャッフル演出
- `test/`: 依存ライブラリ不要の自動テスト
- `manifest.webmanifest` / `sw.js` / `icons/`: PWA
- `scripts/`: 起動・ビルド・アイコン生成

実機でのiOS / Androidホーム画面インストールと音質の確認は、利用する実機・ブラウザでも行ってください。
